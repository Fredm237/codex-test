# FILON — Architecture Decision Records

Les ADR de ce dossier sont les décisions durables du FILON Core. Chaque ADR
documente le contexte, la décision, les alternatives, les conséquences, la
migration et le rollback. Une décision remplacée reste versionnée et reçoit le
statut `superseded` ; elle n'est pas réécrite silencieusement.
